# AGPL-3.0-only license

Shura is open source in a public repository under AGPL-3.0-only. Anyone running a modified Shura server for others must publish their changes, which protects against closed forks of the server, while the code stays fully open for players, contributors and self-hosters. MIT was the simpler alternative, but it would allow closed commercial copies. Relicensing later would need every contributor's consent, which is why this is recorded as a decision.
